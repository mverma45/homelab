The grep Command

grep Display lines matching a pattern
grep Options
-i perform a search, ignoring case
-c Count the number of occurrences in a file
-n Precede output with line numbers.
-v Invert Match. Print lines that don't match.

to search for contents of a file do cat file name
example if we had a file named secret we can do cat secret
to search for the contents of the file we do grep user secret
it will find the file named user
grep o secret will return all occureances that match that file.
to do an inverse we can do 
grep -v o secret that will return all the files that do not contain those files.
to ignore the case we use i grep -i User secret
that will ignore the case
